# Taxi-Fare-Prediction-Analysis_by_mds

🚖 Taxi Fare Prediction & Payment Analysis
Project Overview

This project analyzes taxi trip data to understand the relationship between payment type, trip duration, and fare amount. Using Exploratory Data Analysis (EDA), statistical hypothesis testing, and Linear Regression, the project identifies patterns that can help optimize taxi revenue.

Objectives
Analyze customer payment behavior.
Compare card and cash payments.
Test whether payment type affects fare amount.
Build a Linear Regression model for fare prediction.
Generate business insights for revenue optimization.

Key Findings
Card payments accounted for approximately 67% of all transactions.
Most trips were short-distance rides.
Fare amount increased with trip duration.
A t-test showed a statistically significant difference between card and cash fare amounts.
The Linear Regression model explained approximately 76% of the variance in fare amount.
Business Recommendation

Taxi companies should continue promoting digital payments while also considering additional features such as trip distance, traffic conditions, surge pricing, and pickup/drop-off locations to improve fare prediction accuracy.
